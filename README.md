# GoService – Plateforme de Services

GoService est une plateforme web developpee dans le cadre du programme PIDEV a l'Esprit School of Engineering (2025-2026). Elle permet de connecter les utilisateurs avec des prestataires de services, de gerer des offres, des evenements, des reclamations et des echanges communautaires, tout en gardant une experience utilisateur simple et coherente.

## Description du projet

GoService regroupe six gestions métiers. Chaque gestion contient des métiers simples, qui couvrent les fonctionnalités de base, et des métiers avancés, qui ajoutent des services plus complets et des automatisations.

L’objectif global de la plateforme est de centraliser ces modules dans une seule application afin de simplifier la recherche, la publication, la réservation et le suivi des interactions entre les utilisateurs et les administrateurs.

## Métiers par gestion

### Forum
- Métiers simples : publication de posts, commentaires, likes et modération de base
- Métiers avancés : chatbot, signalement avancé, sauvegarde et partage de contenu

### Services
- Métiers simples : affichage, création, modification et suppression des services
- Métiers avancés : géolocalisation, recherche enrichie et recommandations

### Utilisateurs
- Métiers simples : inscription, connexion et gestion du profil
- Métiers avancés : authentification avancée et vérifications supplémentaires

### Offres
- Métiers simples : consultation, création et suivi des offres
- Métiers avancés : export PDF, candidatures, recommandations et notifications

### Événements
- Métiers simples : gestion des événements, consultation et participation
- Métiers avancés : assistant IA, export calendrier, QR code et e-mails de participation

### Réclamations
- Métiers simples : création, consultation et suivi des réclamations
- Métiers avancés : réponses, statistiques et traitement amélioré des demandes

## Installation

1. Cloner le repository :

```bash
git clone https://github.com/votre-username/go-service.git
cd go-service
```

2. Installer les dépendances PHP si nécessaire :

```bash
composer install
```

## Utilisation

Pour utiliser ce projet, vous devez disposer d’un environnement de développement local avec les outils suivants :

### Prérequis

- Serveur local (XAMPP / WAMP)
- PHP installé
- MySQL
- Navigateur web (Chrome, Edge, etc.)

### Étapes d’utilisation

1. Lancer le serveur local (Apache et MySQL)
2. Accéder à l’application via :

```bash
http://localhost/GoService-merge
```
