# Accès rapide à phpMyAdmin GoService

## 🚀 3 façons d'accéder à la base de données `goservice` :

### Option 1️⃣ : URL directe (PLUS RAPIDE)
```
http://localhost:8888/phpMyAdmin5/index.php?db=goservice
```
Collez cette URL dans votre navigateur et vous verrez goservice directement !

---

### Option 2️⃣ : Fichier HTML local
Ouvrez : `phpmyadmin_goservice.html`
(Il redirige automatiquement vers goservice dans phpMyAdmin)

---

### Option 3️⃣ : Via la liste phpMyAdmin
1. Allez à : http://localhost:8888/phpMyAdmin5/
2. Cliquez sur "Bases de données"
3. **Scrollez vers le bas** pour voir goservice
4. Cliquez sur "goservice"

---

## 📊 Une fois dans goservice, vous verrez :

| Table | Fonction |
|-------|----------|
| **users** | Utilisateurs, Providers, Admins |
| **services** | Services offerts |
| **events** | Événements |
| **forum_posts** | Posts du forum |
| **forum_comments** | Commentaires du forum |
| **offers** | Offres promotionnelles |
| **reclamations** | Réclamations utilisateurs |
| **bookings** | Réservations de services |
